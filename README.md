## 🚀 Featured Projects

### 🤖 [Resonance: AI Resume Analyzer & Interview Assistant](https://github.com/ankurgandhi8789/AI-Resume-Analyzer-Interview-Prep)

An AI-powered tool that analyzes a resume against a target role and prepares the candidate for interviews.

- **RAG pipeline** over a role-knowledge corpus using LangChain and Gemini embeddings
- **Real-time streaming (SSE)** with parallel LLM calls for a fast, responsive UI
- ATS score, **skill-gap analysis** and role-specific interview question generation
- **Google OAuth** with server-side JWT, and model answers cached in MongoDB

`React (Vite)` `Tailwind` `Framer Motion` `Node.js` `Express` `MongoDB` `LangChain` `Gemini 2.5 Flash`

`React (Vite)` `Node.js` `Express` `MongoDB`

### 🩺 Explainable AI Clinical Decision Support System

A decision-support dashboard for **doctors** to assess diabetes risk, with explanations for every prediction.

- Three-tier architecture: **React frontend, Node/Express backend, Flask ML microservice**
- **XGBoost** model (outperformed Random Forest in testing) with **SHAP** explainability
- Multi-page doctor dashboard built with Vite, Tailwind and Framer Motion
- Based on research papers on diabetes CDSS, SMOTE and SHAP

`React` `Node.js` `Express` `MongoDB` `Flask` `XGBoost` `SHAP`

### 📚 StudyRoom: Virtual Collaborative Study Platform

- Real-time features using **WebSocket / STOMP**
- **JWT** authentication, **PostgreSQL** database
- React + Vite frontend with a **Spring Boot 3** backend

`React` `Spring Boot 3` `PostgreSQL` `WebSocket` `JWT`
